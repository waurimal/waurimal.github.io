# 🌸 와우리말 에듀테크 게임 - 무궁화 꽃이 피었습니다: 영어 런 (Mugunghwa: English Run)

## 📌 주요 특징 및 게임 모드

### 1. 🎮 3대 게임 모드 (교실 단체 vs 개인 참여 vs 솔로 연습)
1. **📺 교실 대형 TV / 호스트 방 만들기 (선생님 화면)**
   - 교실 TV나 빔프로젝터에 100m 실시간 경기장 트랙을 띄우고 4자리 방 번호(예: `7842`) 생성
   - **들어오는 시간 지정**: ⏱️ 60초, 90초, 120초, 180초, 무제한
   - 출제 학년 선택: 초등 3~6학년 2022 개정 교육과정 연동
   - 출발선(0m)에 반 전체 학생들의 아바타가 이름표와 번호를 달고 나란히 도열
2. **📱 학생 기기 입장하기 (스마트폰 / 태블릿 / 크롬북)**
   - 4자리 방 번호와 이름을 입력하고 실시간 참가
   - 터치하기 좋은 큼직한 4지선다 영어 퀴즈 패널
3. **🏃 AI 반 친구들과 달리기 (솔로 연습 모드)**
   - 방 생성 없이 혼자서도 AI 봇 반 친구 14명과 함께 100m 달리기 대결 가능

## 🎯 게임 규칙
- 🟢 **초록불 (술래가 구호 외치는 중)**: 퀴즈를 맞히면 앞으로 **+10m** 전진!
- 🔴 **빨간불 (술래가 뒤돌아 주시 중)**: 술래의 눈에서 붉은 레이저 스캔 발사! 움직이거나 오답 시 즉시 적발!
- 🚨 **오답 시 강제 후퇴**: 문제를 틀리면 직전 **안전 체크포인트(25m, 50m, 75m 또는 출발선 0m)**로 강제 후퇴!
- 🎁 **트랙 아이템 5종**:
  - ⚡ **부스터 신발**: 다음 정답 시 2배 전진 (+20m)
  - 🛡️ **방어막 쉴드**: 오답 및 술래 감시 1회 방어 세이프
  - ⏱️ **타임 캡슐**: 남은 시간 +10초 추가
  - 🎯 **50:50 힌트 패스**: 오답 선택지 2개 소거
  - ⭐ **황금 스타 대시**: 무적 대시
