# 나만의 손글씨 마스터 폰트 빌더 (MyHandwriting Font Builder)

사용자가 종이에 작성한 손글씨 스캔 이미지(한글 96자 + 영문/기호 94자)로부터 유니코드 한글 전체 11,172자와 영문 52자, 숫자 10자, 특수기호 32자를 100% 자율 합성 및 컴파일하는 트루타입(TTF) & 웹폰트(WOFF2) 생성 파이프라인입니다.

---

## 1. 폰트 사양
* **글꼴 이름**: MyHandwriting
* **포맷**: TTF (TrueType), WOFF2 (Web Open Font Format 2.0)
* **총 수록 글리프**: 11,268자
  - 현대 한글 전수: 11,172자 (`U+AC00` ~ `U+D7A3`)
  - 영문 알파벳: 52자 (대문자 `A~Z`, 소문자 `a~z`)
  - 숫자: 10자 (`0~9`)
  - 키보드 특수기호: 32자 (`!@#$%^&*()_+-=[]{}|;:,.<>?/\`~`)
  - 특수 글리프: `.notdef`, `space`

---

## 2. 핵심 알고리즘 및 특징
1. **정밀 자소 분해 & 복합모음 조판 엔진**:
   - `clean_e`: 순수 `ㅓ`(- |)와 `ㅣ`(|) 분리 정제 (초성 충돌 및 겹침 제로).
   - `clean_ae`: `| - |` 구조의 순수 `ㅐ` 모음 유지.
   - `clean_o`: 단일 기둥 정통 `ㅗ` 모음 (`debug_clean_true_o.png`).
   - `clean_u`: '무'에서 추출한 완전무결한 정통 `ㅜ` 모음.
   - `clean_eu`: '으'에서 추출한 순수 수평 `ㅡ` 모음.
   - `pure_i`: 높이 55px 온전한 수직 `ㅣ` 모음.
2. **복합모음 유받침(C-type) 황금비율 3단 조판**:
   - `웹`, `완`, `원`, `월`, `광`, `황` 등 복합모음 받침 글자에 대해 초성(좌상단), 가로모음(중앙좌측), 세로모음(우상단, 높이 52%), 종성(하단 중앙 전체) 배치로 안정적인 조형미 확립.
3. **초성 하단 온전 복원**:
   - 기계적 슬라이스로 초성 밑단이 잘리던 문제를 해결하고, 온전한 초성 라이브러리를 전수 매핑하여 `느`, `그`, `드` 등의 하단 끊김 현상 원천 차단.
4. **모폴로지 획 두께 선명화 (Stroke Reinforcement)**:
   - 3x3 타원형 팽창 커널 및 단단한 이진화 처리로 모든 크기에서 획이 흐려지거나 날아가지 않고 선명하고 진한 흑색 렌더링 지원.
5. **영문/기호 타이포그래피 메트릭스**:
   - 베이스라인 정렬 및 어센더(`b`, `d`, `h` 등) / 디센더(`g`, `j`, `p`, `q`, `y`) 음수 오프셋 정렬 적용.

---

## 3. 재빌드 방법
```bash
python build_full_11172_font.py
```
