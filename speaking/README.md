# 🗣️ 영어 말하기 (Speaking Dialogue)

AI 컴퓨터 원어민 파트너와 실시간으로 대화를 주고받는(핑퐁 롤플레잉) 대화형 영어 말하기 에듀테크 웹 프로그램입니다.

---

## 🌟 주요 기능 및 특징

### 1. 🤖 컴퓨터와 실시간 핑퐁 대화 (Interactive Dialogue)
- **컴퓨터 차례 (A)**:
  - AI 파트너가 고품질 원어민 음성(Web Speech TTS)으로 자연스럽게 질문이나 대사를 발화하며 대화창에 말풍선이 뜹니다.
  - 파트너 캐릭터 3종 지원:
    - 🤖 **버디 (Buddy)**: 친절하고 다정한 표준 톤
    - 👧 **에밀리 (Emily)**: 밝고 경쾌한 친구 톤
    - 👨‍🏫 **케빈 (Kevin)**: 차분하고 정확한 선생님 톤
- **학생 차례 (B)**:
  - 학생의 턴이 되면 마이크가 활성화되고, 컴퓨터의 질문에 맞는 영어 답변을 큰 소리로 발화합니다.
  - 발화 즉시 Web Speech STT 엔진이 학생의 음성을 텍스트로 변환하고 레벤슈타인 알고리즘으로 발음 일치율(%)과 반응 스피드를 정밀 채점합니다.
  - 학생의 답변 말풍선과 인식 결과가 대화창에 누적되어 실제 메신저나 회화 대화처럼 자연스러운 인터랙션을 제공합니다.

### 2. 🎯 도전 모드 (난이도 선택)
- **🌱 일반 모드 (기본 1x 점수)**:
  - 학생 대사 영역에 영어 문장과 한국어 해석이 함께 표시됩니다.
  - 🔊 **원어민 발음 듣기(TTS)** 버튼을 눌러 정답 억양과 발음을 먼저 들어보고 연습할 수 있습니다.
  - 초급 학습자나 대화 패턴을 익히는 단계에 최적화되어 있습니다.
- **🔥 고급 모드 (해석만 보고 영어로 대답하기 • 점수 2배 더블 ⚡)**:
  - 상대방(컴퓨터)의 대사는 영어 음성과 자막이 정상 제공됩니다.
  - **내 차례의 영어 문장은 가림막(블라인드) 처리**되고, 오직 **한국어 의미(상황/뜻)**만 화면에 제시됩니다.
  - 학생은 한국어 뜻을 보고 스스로 영어 문장을 구성하여 마이크로 컴퓨터에게 대답해야 합니다.
  - 발화 전에는 원어민 듣기가 제한되며, 발화 완료 후 정답 영어 문장과 원어민 음성이 공개됩니다.
  - 높은 난이도에 상응하여 **획득 점수가 2배(턴당 최대 240점)**로 계산되어 명예의 전당 고득점 1위 경쟁에 도전할 수 있습니다!

### 3. 🏆 실시간 명예의 전당 & 학급 랭킹
- **실시간 Firestore 동기화**: 대화 완주 즉시 학급 및 전교 랭킹에 무지연 자동 반영 (`speaking_scores` 컬렉션).
- **다차원 필터링**: 기간별(전체, 이번 달, 이번 주), 단원별, 학년/반별, **난이도 모드별(전체, 일반, 고급)** 랭킹 조회.
- **학생 개인정보 보호**: 와우리말 표준 **이름 마스킹(홍O동)** 적용.

### 4. 👩‍🏫 교사 관리자 모드
- **대화 단원 편집 및 클라우드 DB 저장**:
  - `A: 영어 대사 : 한국어 해석`
  - `B: 영어 대사 : 한국어 해석`
  - 형식으로 자유롭게 단원별 대화문을 추가/수정/삭제하고 Firebase Firestore(`speaking_units`)에 영구 저장 가능.
- **성적표 리포트 & CSV 엑셀 다운로드**:
  - 순위, 학생 이름, 학적, 학습 단원, **모드(일반/고급)**, 점수, 평균 정확도, 소요 시간, 일시가 포함된 종합 성적표 제공.
- **학급 성적 일괄 삭제 기능**: 학년/반 단위 시험이나 연습 후 데이터 깔끔 정리 지원.

## 🚀 기술 스택
- **프론트엔드**: HTML5, Vanilla JavaScript (ES Module), Tailwind CSS
- **음성 기술**: Web Speech API (`SpeechRecognition` + `SpeechSynthesis`)
- **백엔드/데이터베이스**: Google Firebase Firestore
- **디자인/테마**: Pretendard 웹폰트, FontAwesome 6, 와우리말 공통 에듀테크 UI/UX 규격
