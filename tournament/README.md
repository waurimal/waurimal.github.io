# 🏆 스마트 토너먼트 배정기 (Smart Tournament Bracket) - 팬시 프리미엄 에디션

학급 활동, 체육 대회, 교내 리그, 퀴즈 및 e스포츠 대결 등 학교 현장에서 누구나 손쉽고 공정하게 대진표를 추첨하고 실시간으로 관리할 수 있는 와우리말 에듀테크 토너먼트 웹 애플리케이션입니다.

---

## 🌟 주요 기능 및 팬시(Fancy) 디자인 특징

### 1. 🎨 4종 프리미엄 테마 시스템
- **🌟 골든 챔피언십 (Golden Championship Dark)**: e스포츠 및 챔피언스리그 전광판 스타일의 고급스러운 다크 & 골드 네온 테마.
- **💎 사이버 네온 (Cyber Neon Arcade)**: 딥 네이비와 네온 사이언 & 핑크 글로우가 살아있는 게이밍 아케이드 테마.
- **⚽ 스타디움 스포츠 (Stadium Energy)**: 산뜻한 잔디와 활기찬 오렌지 트랙 분위기의 학교 체육대회 테마.
- **❄️ 모던 블루 (Clean Crystal Light)**: 깨끗하고 세련된 크리스탈 글래스모피즘 에듀테크 테마.

### 2. ⚡ 동적 SVG 브래킷 연결선 & 승자 진출 네온 글로우 (Winner Path Flow)
- 대진표 매치 간을 잇는 직관적이고 정확한 **SVG 계단형(Stepped) 연결선** 자동 렌더링.
- 경기 승자 진출 시, 해당 연결선이 **빛나는 네온/골드 그라디언트(`winner-path`)**로 점등되며 다음 라운드 카드로 에너지가 흐르듯 연결.
- 최종 챔피언 탄생 시, 1라운드부터 결승까지 챔피언이 올라온 전 경로가 **찬란한 24K 골드(`champion-path`)**로 발광.

### 3. 🎲 두구두구 공식 대진 추첨 쇼 (Slot Machine Draw Ceremony)
- 전자칠판/대형 TV 화면에 띄우고 반 전체 학생이 환호하며 볼 수 있는 **슬롯머신 대진 추첨 연출**.
- 경기별 슬롯에서 학생들의 이름이 와르르 롤링되다가 긴장감 넘치는 효과음과 함께 `착!`, `착!` 확정되는 시각/청각 쇼.
- `[⏩ 건너뛰기]`, `[⚡ 2배속 모드]`, `[⏸️ 일시정지]` 컨트롤 지원.

### 4. 🪙 교실 선공/순서 결정 미니 툴 (Classroom Decider Toolkit)
- 경기 전 "누가 먼저 공격할지", "자리/색상 선택"을 즉석에서 공정하게 결정할 수 있는 내장형 도구함:
  1. **🪙 3D 동전 던지기 (Coin Flip)**: 3D 회전 애니메이션과 금속 짤랑 사운드가 구현된 동전 플립.
  2. **🎲 주사위 배틀 (Dice Battle)**: 블루 vs 레드 주사위가 구르며 높은 쪽이 선공을 차지하는 배틀.
  3. **✌️ 가위바위보 대결 (RPS Showdown)**: 3-2-1 카운트다운 후 무작위 손모양 대결.

### 5. 📊 전광판 스코어보드 & 승자 자동 진출
- 세트 점수나 경기 득점을 `+1`, `-1` 스텝 버튼으로 빠르게 조작하는 모던 스코어보드.
- 점수 입력 후 저장 시 높은 점수를 얻은 선수가 다음 라운드로 자동 진출.

### 6. 🔍 대진표 줌/팬 & 화면 맞춤 (Zoom & Auto-fit)
- 16강, 20명, 24명, 26명(1학급 전원), 32강 등 대규모 대진표도 한눈에 볼 수 있는 줌 컨트롤 (`-`, `100%`, `+`, `📐 화면 맞춤`).

### 7. 👑 우승자 시상식 & 영광의 3D 포디움
- 결승전 종료 즉시 다채로운 **콘페티(Confetti) 폭죽** 이 화면 가득 폭발.
- 1위(우승 🏆), 2위(준우승 🥈), 3위(동메달 🥉) 포디움 시상대와 트럼펫 팡파레 멜로디.

### 8. 📸 고화질 PNG 이미지 저장 & A4 인쇄 최적화
- **html2canvas 기반 고화질 이미지 다운로드**: 학급 알림장, 밴드, 클래스팅 공유용.
- **A4 인쇄 최적화 (`window.print`)**: 흑백 인쇄 및 용지에 맞춘 깔끔한 출력 지원.
- **실시간 자동 임시저장**: 브라우저를 닫아도 `localStorage`에 대진 상태 자동 보존.

## 🚀 기술 스택
- **프론트엔드**: HTML5, Vanilla JavaScript (ES6+), Tailwind CSS
- **이펙트/그래픽**: SVG Dynamic Paths, canvas-confetti, html2canvas, FontAwesome 6, Pretendard 웹폰트
- **오디오**: Web Audio API Synthesizer (사운드 파일 없이 코드로 실시간 합성하는 경량 무지연 사운드 엔진)
- **와우리말 에듀테크 GNB 규격 준수** (`waurimal-nav.js`)
