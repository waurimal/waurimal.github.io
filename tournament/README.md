# 🏆 스마트 토너먼트 배정기 (Smart Tournament Bracket)

학급 활동, 체육 대회, 교내 리그, 퀴즈 및 보드게임 대결 등 학교 현장에서 누구나 손쉽고 공정하게 대진표를 추첨하고 실시간으로 관리할 수 있는 에듀테크 토너먼트 웹 애플리케이션입니다.

---

## 🌟 주요 기능 및 특징

### 1. 👥 유연한 참가자 명단 및 자동 부전승(BYE) 처리
- **다양한 참가 단위**: 학생 개인전(1인 1슬롯) 및 모둠/팀 대항전(모둠별 슬롯) 완벽 지원.
- **간편한 명단 입력**: 텍스트 복사-붙여넣기(줄바꿈 또는 쉼표 구분)로 한 번에 명단 등록.
- **원클릭 빠른 인원 프리셋**:
  - 4명, 6명, 8명(8강), 12명, 16명(16강), 20명, 24명, 25명/26명(1학급 전원), 6모둠, 8모둠 프리셋 원클릭 적용.
- **스마트 자동 부전승(BYE)**:
  - 2의 거듭제곱(4, 8, 16, 32강)에 맞지 않는 임의의 인원(예: 5명, 7명, 11명, 25명 등)도 국제 표준 토너먼트 룰에 따라 균형 있게 부전승을 자동 배정하여 1라운드를 매끄럽게 통과시킵니다.

### 2. 🎲 긴장감 넘치는 3종 대진 배정 방식
- **🎲 두구두구 랜덤 추첨**:
  - 전자칠판/대형 스크린에 띄우고 반 전체 학생이 지켜볼 때 긴장감과 몰입감을 주는 슬롯/스핀 애니메이션 연출.
  - Web Audio API 기반 드럼롤 및 카운트다운 사운드 효과 제공.
- **⚡ 즉시 자동 배정**: 대기 시간 없이 즉시 균형 있게 랜덤 셔플하여 대진표 구성.
- **🔢 입력 순서대로 배정**: 시드 순위나 이전 경기 성적순으로 배치하고자 할 때 사용.

### 3. 🔄 1라운드 자리 맞교환 (Swap) 기능
- 대진표가 완성된 후, 교사의 지도에 따라 특정 학생 간 자리를 원클릭으로 맞바꿀 수 있는 맞교환 모드 지원.

### 4. 🖱️ 직관적인 원클릭 인터랙티브 브래킷
- 경기 카드의 승자 슬롯을 클릭하면 **즉시 다음 라운드로 자동 진출**!
- 필요 시 연필 아이콘(✏️)을 눌러 세부 세트 점수(예: `2 : 1`, `5 : 3`)를 기록할 수 있습니다.
- 잘못 클릭한 경우 다시 클릭하여 승자 선택 취소 및 재배정 가능.

### 5. 🥉 3·4위전 (동메달 결정전) 자동 연동
- 준결승(4강)에서 아쉽게 패배한 두 선수를 자동으로 3·4위전에 배정하여 동메달리스트를 결정할 수 있습니다 (옵션으로 켜고 끄기 가능).

### 6. 👑 우승자 시상식 & 영광의 포디움
- 결승전 종료 즉시 화면 가득 화려한 **콘페티(Confetti) 폭죽** 이 쏟아집니다.
- 1위(우승 🏆), 2위(준우승 🥈), 3위(동메달 🥉) 포디움 시상대와 축하 팡파레 멜로디가 연출됩니다.

### 7. 📸 대진표 이미지 저장 & A4 인쇄
- **고화질 PNG 이미지 저장 (`html2canvas`)**: 완성된 대진표나 진행 상황을 캡처하여 학급 알림장, 밴드, 클래스팅에 즉시 공유.
- **A4 인쇄 최적화 (`window.print`)**: 브라우저 인쇄 시 버튼이나 여백을 제거하고 대진표만 깔끔하게 출력.
- **실시간 자동 임시저장**: 브라우저를 실수로 닫아도 `localStorage`에 현재 대진 상태가 자동 보존됩니다.

- **프론트엔드**: HTML5, Vanilla JavaScript (ES6+), Tailwind CSS
- **이펙트/그래픽**: canvas-confetti, html2canvas, FontAwesome 6, Pretendard 웹폰트
- **오디오**: Web Audio API Synthesizer (무설치 경량 사운드 엔진)
- **와우리말 에듀테크 GNB 규격 준수**
