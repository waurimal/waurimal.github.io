# 🚀 우주 단어 수호대: 스펠링 갤러그 (Spelling Galaga)

초등학교 교실 및 크롬북(Chromebook) 환경에 완벽 최적화된 **갤러그(Galaga) 아케이드 스타일의 교육용 영어 스펠링 슈팅 게임**입니다.

---

## 🎮 게임 개요 및 핵심 룰

1. **상단 목표 단어 뜻 확인 & 스펠링 조준 격추**:
   - 화면 상단 전광판에 현재 맞춰야 할 단어의 **한국어 뜻**이 표시됩니다 (예: `목표 뜻: 사과`).
   - 단어 글자 수에 맞춰 스펠링 슬롯(`_ _ _ _ _`)이 생성됩니다.
   - 고전 갤러그 외계인 편대(초록 파리 Zako, 빨간 나방 Goei, 보스 갤러그)들이 알파벳을 품고 편대 비행을 펼칩니다.
   - 목표 단어의 철자 순서에 맞춰 올바른 알파벳을 품은 외계인을 조준 격추해야 합니다.

2. **❤️ 5개 목숨(Lives) 시스템**:
   - 시작 시 **하트 5개(❤️ ❤️ ❤️ ❤️ ❤️)**가 주어집니다.
   - 단어의 순서에 맞지 않는 엉뚱한 철자를 격추하거나, 적 기체 및 적의 탄환과 충돌하면 **목숨이 1개 차감**됩니다.
   - **총 5번 실패(목숨 0개)하면 게임 오버**가 됩니다.

3. **⚡ 듀얼 파이터 (Dual Fighter) & 트랙터 빔 구출**:
   - 보스 갤러그가 급강하할 때 뿜어내는 푸른 인력 광선(트랙터 빔)에 아군 기체가 납치될 수 있습니다.
   - 보스가 납치된 기체를 달고 다음 급강하를 할 때, 아군 기체를 피하고 보스를 격추하면 아군 기체를 구출하여 **강력한 2연장 듀얼 파이터(Dual Fighter)**로 합체합니다!
   - 듀얼 파이터 상태에서는 2발의 미사일을 동시에 연사하여 막강한 화력을 자랑하며, 피격 시 목숨 대신 1대의 파이터만 소실되는 방어 효과를 가집니다.

4. **🎁 우주 드롭 파워업 아이템**:
   - 적 외계인을 연속 콤보로 처치하거나 급강하 적을 격추하면 유용한 8비트 캡슐 아이템이 드롭됩니다:
     - ❤️ **하트 (Heart)**: 목숨 +1 회복 (최대 5개까지)
     - ⚡ **듀얼 (Dual)**: 듀얼 파이터 즉시 변신
     - 🛡️ **쉴드 (Shield)**: 적 탄환 및 충돌 1회 완벽 방어
     - 💣 **폭탄 (Bomb)**: 화면 내 모든 오답 방해 외계인을 일소하는 스마트 EMP
     - ⏱️ **슬로우 (Slow)**: 8초간 적 비행 속도와 탄환을 50% 감속시키는 시공간 워프

5. **🎯 수준별 맞춤 3단계 난이도 모드**:
   - 🟢 **초급 (Easy / 힌트)**: 상단 슬롯에 목표 알파벳 직접 표시 + 해당 외계인에 황금빛 네온 펄스 후광 제공
   - 🟡 **중급 (Normal / 표준)**: 상단 슬롯에 `?` 표시 + 해당 외계인에 은은한 뱃지 테두리
   - 🔴 **고급 (Hard / 암기)**: 상단 슬롯에 `_`만 표시 + 모든 외계인 동일 외관 (단어 철자를 머릿속으로 떠올려 스스로 찾아 격추하는 완전 기억 챌린지)

6. **단어 완성 팡파르 & 영어 원어민 TTS 발음**:
   - 단어를 끝까지 완성하면 화려한 워프 연출과 폭죽, 축하 보너스 점수(+500점)가 주어집니다.
   - 브라우저 Web Speech API를 통해 원어민 발음이 자동 재생됩니다.

## 💻 크롬북(Chromebook) 및 조작 가이드

- **키보드 조작**:
  - `←`, `→` 또는 `A`, `D`: 전투기 좌우 이동 (이동 시 기체가 자연스럽게 기울어지는 롤링 뱅크각 적용)
  - `Spacebar` 또는 `Enter`: 미사일 발사 (누르고 있으면 자동 연사)
- **터치스크린 & 마우스 조작 (2-in-1 크롬북 완벽 대응)**:
  - 화면 드래그: 손가락이나 마우스를 따라 부드럽게 기체 이동
  - 화면 터치 또는 우측 하단 `FIRE` 버튼: 미사일 발사
- **크롬북 전체화면**:
  - 상단 메뉴의 `⛶ 전체화면` 버튼을 누르면 크롬북 화면 전체에 꽉 차는 풀스크린 아케이드 모드로 전환됩니다.

## 👩‍🏫 선생님 맞춤 기능 (EdTech Features)

1. **와우리말 공통 교육과정 (WaurimalCurriculum) 완벽 연동**:
   - 초등 3~6학년 정규 영어 교과서 1~12단원 전 단원의 필수 어휘를 단어장 메뉴에서 원클릭으로 선택 가능합니다.
2. **기본 및 테마 단어장**:
   - 3학년, 4학년, 5학년, 6학년 학년별 필수 단어장
   - 동물 탐험대, 우주 모험 스페셜 단어장
3. **선생님 맞춤 단어 등록기 (Custom Words)**:
   - 상단 `✏️ 맞춤 단어` 버튼을 눌러 오늘 수업에서 배울 단어들을 자유롭게 추가할 수 있습니다.
   - `APPLE: 사과` 형식으로 한 줄씩 입력 후 저장하면 `localStorage`에 보관되어 재사용됩니다.
4. **실시간 명예의 전당 (Hall of Fame TOP 30)**:
   - Firebase Firestore 연동을 통해 학급/학교 실시간 순위표를 지원합니다.
   - 동점자 표준 순위 처리(1224 순위제) 및 학생 개인정보 보호를 위한 이름 마스킹(`이O연`)이 적용됩니다.
5. **학습 결과 리포트 & 오답 노트**:
   - 게임 종료 시 학생이 맞힌 단어와 틀린 단어 목록, 사격 명중률을 한눈에 확인하고 `🔊 듣기` 버튼으로 복습할 수 있습니다.

## 🔊 100% 무설치 8-Bit Web Audio 기술

- 외부 mp3, wav 파일 다운로드가 일체 필요 없습니다.
- HTML5 **Web Audio API**의 오실레이터와 노이즈 제너레이터로 고전 갤러그 오리지널 팡파르, 레이저 발사음, 폭발음, 트랙터 빔 음향, 듀얼 도킹 팡파르, 8비트 아케이드 BGM을 실시간 합성하므로, 학교 네트워크 트래픽 부담이 0%이며 오프라인에서도 즉시 구동됩니다.
