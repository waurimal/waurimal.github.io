# 🎲 와우리말 에듀테크 영어 윷놀이 (English Yutnori)

대한민국 전통 민속놀이인 **윷놀이**에 초등 영어 교육과정(단어 및 문장)을 접목한 웹 기반 에듀테크 보드게임입니다.

- **배포 주소**: [https://waurimal.github.io/yutnori/index.html](https://waurimal.github.io/yutnori/index.html)
- **제작/운영**: 와우리말(Waurimal) 프로젝트 (2026)

---

## 📌 주요 특징 및 기능

### 1. 🎮 게임 모드
1. **🤖 컴퓨터 대전 (AI 연습 모드)**
   - 초기 화면에서 '컴퓨터 대전' 선택 시 즉시 게임판으로 진입하여 혼자서 플레이 가능
   - 3단계 난이도 제공:
     - **순한맛 (쉬움)**: 정답률 70%, 초심자 추천
     - **보통맛 (표준)**: 정답률 85%, 균형 잡힌 AI
     - **매운맛 (도전)**: 정답률 96%, 지름길 및 잡기/업기 적극 공략
   - 컴퓨터 차례 시 퀴즈 피드백 팝업 자동 닫힘 (0.8초 후) 지원으로 쾌적한 템포 유지

2. **📡 실시간 온라인 멀티플레이 (Firebase Firestore)**
   - **4자리 숫자 방 코드** 공유 시스템
   - **1:1 개인전** 및 **학급 전체 무제한 팀전 (청팀 vs 백팀)** 지원 (인원 제한 없이 반 전체 30명 이상 동시 참여 가능)
   - 실시간 대기실(로비)에서 청팀/백팀 자유 변경, 원클릭 팀 균등 배정 및 방장 게임 시작 제어
   - 팀원 수가 달라도 청팀과 백팀이 1:1로 엄격하게 교차하며 팀 내 모든 학생이 공평하게 순환 턴 진행
   - 윷 던지기, 퀴즈 풀이 결과, 말 이동 애니메이션 및 말 잡기/업기 실시간 동기화

### 2. 🪓 전통 윷놀이 보드 시스템 (29-Node Topology)
- **정통 윷판 29개 노드 완전 구현**:
  - 외곽 순환 경로 (`OUTER`: 0 ~ 19번 노드)
  - 우상단 모서리(5번) 진입 대각선 경로 (`CORNER1`: 20 ~ 24번 노드)
  - 좌상단 모서리(10번) 진입 대각선 경로 (`CORNER2`: 25 ~ 26, 22 ~ 24번 노드)
  - 정중앙 방(22번) 도착 시 최단 지름길 출구 (`CENTER_OUT`: 27, 28, 0번 노드)
- **3D 실사 윷가락 비주얼 & 애니메이션**:
  - 4개 윷가락의 3D 덤블링 롤링 애니메이션
  - 밝은 면(앞/배 - 평평함, X눈금)과 짙은 면(뒤/등 - 둥근 등, 껍질 무늬) 시각화
  - 1번 윷가락 빽도 전용 붉은색 표식 및 개별 상태 뱃지 표시
- **정통 윷놀이 특수 룰**:
  - **빽도(뒷도, -1)**: 판 위의 말 1칸 후퇴, 대기실에서 첫 빽도 시 19번 칸(골인 직전) 순간이동
  - **윷 / 모 / 말 잡기 보너스**: 윷이나 모가 나오거나 상대 말을 잡았을 때 한 번 더 던지기(`pendingExtraTurn`)
  - **말 업기 (Stacking)**: 아군 말이 같은 칸에 도착하면 한 몸(x2, x3, x4)이 되어 이후 턴에서 동시 전진
  - **말 잡기 (Capturing)**: 적군 말이 있는 칸에 도착하면 적군 말을 대기실로 퇴출시키고, 뭉쳐있던 말은 완전히 분리되어 각자 대기실에서 새로 출발

### 3. 📚 학년별 영어 퀴즈 시스템 (`questions.js`)
윷을 던진 후 말을 선택하면 **영어 문제를 맞혀야 전진**할 수 있습니다. 3학년, 4학년, 5학년, 6학년 개별 수준별로 교육과정에 완벽 정합된 어휘 306개와 핵심 문장 134개가 탑재되어 있습니다.

- **학년별 출제 범위 선택**:
  - **🌱 초등 3학년 수준**: 알파벳 기초, 색깔, 숫자, 신체, 가족, 동물, 학용품, 기초 의사소통 (88단어 / 35문장)
  - **🌿 초등 4학년 수준**: 시간, 날씨, 계절, 길 안내, 장소, 식사, 스포츠, 규칙/금지 (75단어 / 33문장)
  - **🌲 초등 5학년 수준**: 교과목, 월/서수, 생일/날짜, 과거 경험, 건강/증상, 여가 빈도 (73단어 / 33문장)
  - **🌟 초등 6학년 수준**: 미래 진로/직업, 감정 이유, 비교급, 환경/지구 보호, 세계 문화, 제안 (70단어 / 33문장)
  - **초등 3~4학년군 군별 종합** & **5~6학년군 군별 종합**
  - **초등 전학년 종합 (3~6학년 총 306단어 & 134문장)**
- **6대 퀴즈 출제 유형**:
  1. **영단어 뜻 맞추기 (word_to_kr)**: 단어 제시 ➔ 한국어 뜻 4지선다형 (원어민 TTS 자동 재생)
  2. **우리말 뜻 영단어 맞추기 (kr_to_word)**: 뜻 제시 ➔ 영단어 4지선다형
  3. **스펠링 빈칸 채우기 (word_spelling)**: 단어 내 핵심 알파벳 빈칸(_) 맞추기
  4. **영어 문장 해석 고르기 (sent_to_kr)**: 문장 제시 ➔ 올바른 우리말 해석 4지선다형
  5. **문장 속 핵심 단어 빈칸 채우기 (sent_blank)**: 문맥에 맞는 핵심 빈칸 단어 선택
  6. **단어 카드 문장 어순 배열 (sent_scramble)**: 단어 블록을 클릭/터치하여 올바른 영어 문장 완성
- **모달 퀴즈 배지**: 출제된 문제의 학년 수준(`3학년 수준`, `4학년 수준`, `5학년 수준`, `6학년 수준`)이 모달 상단에 시각적으로 배지 표시됨

### 4. 🏆 학생 실명제 & 명예의 전당 (Hall of Fame)
- **실명제 시스템**:
  - 닉네임 대신 학생 본인의 실명(이름) 필수 사용
  - 와우리말 공통 학생 프로필(`WaurimalStudent`) 및 `localStorage` 자동 연동
- **기여도 및 승수 중심 점수 산출 공식**:
  $$\text{총 점수} = (\text{승수} \times 500) + (\text{퀴즈 정답} \times 50) + (\text{완주} \times 150) + (\text{말 잡기} \times 100) + (\text{말 업기} \times 40) + (\text{윷/모} \times 30)$$
- **대시보드 노출**:
  - 초기 화면 우하단 TOP 5 실시간 기여도 랭킹 위젯 상시 노출
  - 헤더 [명예의 전당] 클릭 시 전체 누적 순위 및 상세 통계 모달 제공

## 🛠️ 주요 버그 수정 및 개선 이력

1. **윷가락 시각화 개선**: 윷가락 4개의 앞면(배)/뒷면(등) 상태 텍스트 뱃지와 빽도윷 표식을 추가하여 도/개/걸/윷/모 결과를 한눈에 파악 가능하도록 개선
2. **명예의 전당 초기 노출**: 초기 화면 우측에 TOP 5 랭킹 위젯을 기본 배치하고 기여도 가중치 산출 공식 적용
3. **AI 대전 팝업 자동 닫힘**: 컴퓨터가 퀴즈를 맞힌 경우 사용자가 확인 버튼을 누를 필요 없이 0.8초 후 자동으로 닫히고 다음 동작 수행
4. **4자리 코드 기반 실시간 멀티플레이 완성**: Firebase Cloud Firestore `yutnori_rooms` 컬렉션을 활용한 방 코드 발급 및 실시간 팀 배정 대기실 구축
5. **실명 시스템 도입**: 모든 모드에서 닉네임 대신 학생 실명을 필수로 입력받도록 개편
6. **초기 화면 컴퓨터 대전 즉시 시작**: 설정 모달에서 '컴퓨터 대전' 클릭 시 대기 없이 모달이 닫히며 즉시 게임판 진입
7. **말 업기 및 잡기 로직 정밀화**:
   - 위치 기반 그룹핑(`getPieceGroup`)을 적용하여 뭉친 아군 말들이 예외 없이 한 몸으로 동시 이동
   - 적군에게 잡힌 경우 대기실로 퇴출되면서 `stackedPieces`를 완전히 초기화하여, 대기실에서 다른 말이 끌려 나오지 않고 각자 새로 출발하도록 완벽 수정
8. **실시간 온라인 멀티플레이 학급 전체 무제한 참여 지원**:
   - 기존 최대 8명 정원 제한을 해제하여 학급 전체(30명 이상)가 제한 없이 동시 접속하여 플레이할 수 있도록 확장
   - 청팀과 백팀의 인원수가 달라도 1:1로 엄격하게 교차하며 팀 내 모든 학생이 공평하게 순환하는 동적 턴 오더 알고리즘 적용
   - 대기실(로비) 및 결과 모달에 스크롤 지원 및 번호 뱃지 표기, 팀별 인원수 실시간 표시 제공
9. **윷 던지는 사람 설정 및 '모두가 한 번씩 던지기' 기능 추가**:
   - 방 생성 및 실시간 대기실에서 '윷 던지는 사람 설정' 옵션 지원
   - **모두가 한 번씩 던지기 (`all_once` - 기본값 / 수업 권장)**: 윷·모·말 잡기 보너스 기회가 발생해도 같은 학생이 연속으로 던지지 않고 팀 내 다음 학생이 보너스 윷을 던져, 학급 모든 학생이 공평하게 한 번씩 던질 수 있도록 구현
   - **보너스 연속 던지기 (`streak`)**: 전통 윷놀이 규칙으로 윷/모/잡기 시 동일인이 한 번 더 던짐
   - **팀 대표 1인 던지기 (`leader`)**: 각 팀의 대표 학생 1명이 투척과 이동을 전담
   - 방장은 대기실에서 원클릭으로 설정을 자유롭게 토글 변경할 수 있으며, 전체 참가자에게 실시간 안내 뱃지 표출
